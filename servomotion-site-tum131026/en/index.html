PROCESS AND APPLICATION GAINS

ACCURACY AND REPEATABILITY
IN ALIGNMENT WORK

01 / MATERIAL PLACEMENT

EDGE AND AXIS REFERENCE

The defined edge and axis positions are projected onto the working surface as laser lines. The operator places the material or part against a shared reference, which reduces the need to transfer measurements by hand.

02 / MACHINE SETUP

A CONTROLLED SETUP PROCESS

The target positions of guides, stops and processing elements are shown by the laser references. Being able to follow the setup points directly in the working area simplifies commissioning and cuts repeated measurement steps.

03 / PRODUCT CHANGEOVER

REPEATABILITY FROM THE RECIPE

Position data for each product is held in the recipe and reapplied under PLC control at the next changeover. Returning to the same reference layout supports a standard setup method and shortens preparation between products.

CATEGORY DIFFERENCE

NOT A FIXED SETTING.
POSITIONING BY RECIPE.

Traditional fixed reference

The laser is set once at commissioning. Every recipe change then means re-adjusting the line by hand, so the result depends on who does it, how it is measured and how much time is available.

Servo-controlled reference

Dimensions are entered at the panel and the system drives to the target positions itself. Call up the same recipe and the lines return to the same place — changeover becomes a machine task rather than an operator task, improving changeover repeatability.

RUBBER AND COMPOSITE

The lay-up width of the reinforcement plies changes from product to product, so the edge and symmetry reference has to be re-established at every changeover. The reference lines follow the geometry of the application surface.

Decisive factorsPly width, symmetry axis, geometry of the application surface and working distance.

HYGIENE PRODUCTS AND NONWOVEN

Every layer in a multi-ply structure needs a consistent edge and axis reference, while the product size changes often. When the size changes, the alignment positions are rebuilt from the recipe.

Decisive factorsNumber of layers, working width, number of simultaneous reference lines and the optical behaviour of the nonwoven surface.

EXAMPLE INSTALLATION
Shuttle Precisor · 26 lasers · 2,300 mm travel

PACKAGING AND PAPER

Changing between formats holds the line while guides and processing elements are reset. A shared position reference keeps the same setup discipline across formats.

Decisive factorsFormat variety, recipe change frequency and the number of reference lines that must be visible at the same time.

EXAMPLE INSTALLATION
Shuttle Precisor · 16 lasers · 1,800 mm travel

FILM AND FOIL

The job usually starts with where the two edges sit. Reel width and slit width change from recipe to recipe, so the edge position has to be re-established at every changeover.

Decisive factorsSurface optics, distance between the edges, laser colour and working distance.

EXAMPLE INSTALLATION

TEXTILES AND TECHNICAL FABRICS

Symmetry matters as much as edge position. Once the centre axis is lost the product comes out off-centre even when the edges are correct, so the centre reference has to stay visible throughout production.

Decisive factorsLay-up width, centre axis, ply arrangement and mounting height.

EXAMPLE INSTALLATION
Core Precisor · K4 dual channel (2 moving + 1 fixed centre) · 2,400 mm travel
