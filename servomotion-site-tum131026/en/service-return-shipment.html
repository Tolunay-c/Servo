RETURN SHIPMENT

IF A COMPONENT
HAS TO BE SENT BACK

In some cases a component has to be examined in our workshop. This page sets out the process from shipment to redelivery. A call to the helpdesk before you remove anything often makes the shipment unnecessary.

OPEN A REQUEST GO TO THE HELPDESK

FIRST OF ALL

NOT EVERY CASE
NEEDS A SHIPMENT

Talk to the helpdesk before removing a component. Most recipe-, parameter- and mounting-related issues are resolved on site, and an unnecessary shipment costs both time and freight.

Helpdesk first

Let us assess the symptom together by phone. If a shipment is needed, we agree that together.

Get a return number

Once the return is approved, we send you a return number. Shipments that arrive without one cannot be processed, because they cannot be traced back to a system.

Only the relevant component

Do not send the whole system. We agree which component to send during the call.

Warranty scope

Scope and freight responsibility vary by project and are stated in the quotation. We confirm both with you before shipment.

PROCESS

FROM SHIPMENT
TO REDELIVERY

01

ASSESSMENT AND APPROVAL

Talk to the helpdesk. We decide together whether a shipment is needed, and you then receive a return number and the shipping address.

02

PACKING

Ship the component in its original box or in packaging that offers equivalent protection. Optical surfaces and connectors must be protected separately. Mark the return number on both the outside and the inside of the package.

03

SHIPMENT

Include a short fault note with the shipment: the symptom, when it started and which recipe it appeared in. That note speeds up the inspection considerably.

04

INSPECTION AND REPORT

The component is examined in our workshop. The findings, the proposed work and the scope are confirmed in writing, and work begins once you approve.

05

REDELIVERY AND VERIFICATION

The component is tested before dispatch. Once it is refitted on the line, we carry out the verification steps with you.
